# **Selamat Datang di Website Statis KAL**
Website statis KAL (Komputasi Aljabar Linear) adalah platform catatan saya sebagai mahasiswa untuk digunakan sebagai pembelajaran dan dokumentasi catatan yang dapat diakses oleh publik dan saya pribadi.

Salah satu tujuan utama dibuatnya website ini yaitu sebagai bentuk **pengembangan diri** saya dalam bidang pemrograman website dan menjadi sarana pembelajaran mengenai **komputasi aljabar linier**.

Semoga website ini bermanfaat bagi saya dan siapapu yang mengaksesnya. Saya Abdul Hadi Marzuqi sebagai pembuat website statis ini mengucapakan terima kasih atas kunjungannya.
